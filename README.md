# Women Safety Device

## Project Overview
This project is a compact portable personal safety device designed for emergency protection. The device is rechargeable, compact and designed to be affordable.

## Features
• Compact size (~23 cm)
• Rechargeable battery
• Safety switch
• Trigger button
• Portable design

## Components Used
• High voltage generator module
• 3.7V battery
• TP4056 charging module
• Push button switch
• Slide switch
• Electrodes
• Casing

## Cost Analysis
Manufacturing Cost: ₹335  
Selling Price: ₹499  
Profit per unit: ₹164
